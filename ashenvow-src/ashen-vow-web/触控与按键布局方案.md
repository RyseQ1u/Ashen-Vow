# 《灰烬誓约》竖屏单手触控与按键布局方案

> 适用范围：安卓 WebView 封装版（锁竖屏）+ 网页版统一竖屏布局
> 设计基准：屏幕宽 W=390pt、高 H=844pt；内容竖栏 max-width=560pt
> 单位约定：1pt = 1 CSS px = 1 Android dp（@1x 逻辑像素）
> 关联文档：`design-spec.md`、`UI-REWRITE-HANDOFF.md`

---

## 0. 结论先行

《灰烬誓约》是**回合制 4vN 暗黑奇幻 RPG**，无连续方向输入、无时间压力，因此：

1. **触控以「点按 Tap」为唯一高频输入**，不引入摇杆/双指；「长按确认」仅用于不可逆操作兜底。
2. **每屏的「主操作」一律钉死在屏幕底部 22% 高度（A 区）**，右下角（右手）为拇指枢轴，永不放到顶部或对侧边缘。
3. **高危不可逆操作（结束回合、撤退、删除）独立间距 + 长按 300–500ms 确认**，与主操作在物理和心理上双重隔离。
4. **双手兼容**：一键左右手镜像（X 轴翻转 + 语义方向镜像），技能卡顺序、导航栏、主操作落点同步翻转。
5. **自适应**：手机单列、平板 560pt 竖栏居中；命中目标不随屏等比缩小，安全区避让系统手势条。

---

## 1. 拇指可达性分区模型

以屏幕高度 H 划分四档（自底部起算），并以持机手拇指根部为枢轴画「舒适弧」。

| 分区 | 高度区间（基准 844pt） | 位置 | 舒适度 | 用途 | 承载内容 |
|---|---|---|---|---|---|
| **A 主操作区** | 78–100%H（658–844pt） | 底部 | ★★★★★ 最舒适 | 高频、首要 CTA | 技能坞、普攻、结束回合、进入节点、出发 |
| **B 辅助操作区** | 55–78%H（464–658pt） | 中下 | ★★★☆ 舒适边缘 | 次级操作 | 快捷动作、补给、战报、次级按钮 |
| **C 信息/低频区** | 30–55%H（253–464pt） | 中上 | ★★☆ 需上伸 | 信息展示 + 低频点选 | 战场目标、地图节点、建筑卡 |
| **D 只读/低频区** | 0–30%H（0–253pt） | 顶部 | ★☆ 换手区 | 只读 / 偶发 | 行动顺序条、标题、资源栏、撤退 |

**X 轴（右手默认）**：右半屏 + 中央为舒适带；左侧边缘 0–15% 宽为「反手带」，只放只读信息或不常用键。

**拇指舒适弧**：以右下角（约 x=85%W, y=100%H）为枢轴、半径≈45%H（约拇指长）向上扫出的扇形；弧内为「黄金区」，高频操作应尽量落于此。

## 2. 触控方式选型

| 输入 | 用途 | 结论 |
|---|---|---|
| 点按 Tap | 选技能、选目标、进入节点、出发、事件选项 | **主输入，唯一高频手势** |
| 长按 Hold（300–500ms） | 结束回合/撤退/删除等不可逆操作二次确认 | 辅助，防误触 |
| 滑动 Swipe | 仅列表/队伍条横向翻页；不用于核心决策 | 弱化，避免与系统返回手势冲突 |
| 双指/摇杆/重力 | 无对应需求 | 不采用 |

核心操作路径：**点技能卡（A 区）→ 点目标（C 区战场）→ 点结束回合（A 区）**，全在舒适弧内闭环，单次循环拇指行程 ≤ 一次上下摆动。

### 3.1 战斗屏（最重要 · 三段式 100dvh 零滚动）

```
│ D 战况条：标题 + 行动顺序头像条（只读）   │ ← 0–8%H
│           [撤退]  ← 收进左上角（高危低频） │
├─────────────────────────────────────────┤
│ C 战场：双方立绘对峙                       │ ← 8–72%H（flex）
│     点选敌方=目标（红色锁定环，命中区≥72pt）│
│     我方当前单位金色光环（只读）            │
├─────────────────────────────────────────┤
│ A 技能坞：                               │ ← 72–100%H
│   [技能1][技能2][技能3][技能4]  4张横排    │   每张≥64pt高
│   ┌──────────────┬──────────────┐        │
│   │  普攻(64pt)   │ 结束回合(64pt)│        │   主操作行
│   │  最舒适位     │  独立+长按确认 │        │
│   └──────────────┴──────────────┘        │
│   [战报][跳过][绷带] → 44pt 次级图标       │   次级行

```

| 键位 | 尺寸(pt) | 分区 | 功能 | 频率 | 优先级 | 备注 |
|---|---|---|---|---|---|---|
| 技能卡 ×4 | 高 ≥64，宽均分 | A | 选技能 | 高 | P0 | 选中金框+上浮；冷却灰态 |
| 普攻 | 64×64 | A（右下角） | 普攻快捷 | 高 | P0 | 最高频 → 最舒适位 |

### 3.3 营地屏

```
┌─────────────────────────────────────────┐
│ D 资源栏（金币/碎片/第三资源，只读）       │
├─────────────────────────────────────────┤
│ C 场景 + 4 张建筑浮卡（低频）             │
│ B 快捷四动作：治疗/训练/锻造/升级（中频）  │

├─────────────────────────────────────────┤
│ A 固定底栏 64px：           [ 出发 ]CTA  │ ← 右下角，首要
└─────────────────────────────────────────┘
  左侧纵向导航（营地/英雄/档案，低频，靠边）
```

| 键位 | 尺寸 | 分区 | 频率 | 优先级 |
|---|---|---|---|---|
| 出发 CTA | 高 64，固定底栏 | A（右下） | 高 | P0 |
| 快捷四动作 | ≥48×48 | B | 中 | P1 |
| 队伍卡/后备 | ≥44×44 | B | 中 | P1 |
| 建筑卡 | 卡面 | C | 低 | P2 |
| 左侧导航 | ≥44×44 | 左边缘 | 低 | P2 |

### 3.4 其余屏（事件/结算/主菜单/英雄管理）

- **事件屏**：2–3 个选项按钮 `choice` 并排于 B 区（同屏无需滚动），等高 ≥56pt。
- **结算屏**：唯一主操作「返回营地」`camp` 放 A 区吸底，全宽大按钮。
- **主菜单**：4 张主按钮大卡（开始远征/继续游戏/图鉴/设置）排布于中下部，主 CTA「开始远征」高亮且最靠底部。
- **英雄/档案二级页**：当前为长页面（已知限制），操作按钮统一 ≥44×44，高频动作（训练/锻造/招募确认）尽量吸底。

## 4. 高频与低频操作层级划分

原则：**高频优先映射 A 区，其次 B 区；低频与高危收进 C/D 区或二级菜单/抽屉。**

| 层级 | 判定 | 操作（按频率排序） | 落位 |
|---|---|---|---|
| **L1 高频** | 每回合/每步必点 | 结束回合 > 普攻/选技能 > 选目标 > 进入节点 > 出发 > 事件选项 | A 区 |
| **L2 中频** | 每场/每屏数次 | 选节点、战报、快捷动作（治疗/训练/锻造/升级）、补给使用、建筑升级 | B 区 / A 次级行 |
| **L3 低频** | 偶尔用 | 设置、图鉴、存档、导航、装备/饰品/天赋/技能训练（二级页） | C/D 区或二级页 |
| **L4 高危低频** | 偶发但不可逆 | 撤退、结束回合（部分语境）、删除存档、解散英雄 | 角落 + 独立间距 + 确认 |

## 5. 防误触 · 间距、热区、手势规范

### 5.1 尺寸与间距

| 项 | 规范 |
|---|---|
| 最小可点目标 | **44×44pt（约 9mm）** |
| 重要/主操作 | **48–64pt** |
| 首要 CTA（出发/进入节点/普攻/结束回合） | **≥64pt** |
| 相邻目标间距 | **≥8pt** |
| 高危键独立间距 | **≥16pt**，且与主操作物理分区 |
| 目标命中区（敌人/节点） | 视觉元素 + 放大命中区，**≥72pt** |

### 5.2 手势判定阈值

| 手势 | 判定 | 说明 |
|---|---|---|
| Tap 点按 | 位移 <8pt 且时长 <300ms | 触发 |
| Long-press 长按 | 时长 ≥300ms（高危操作建议 500ms） | 触发二次确认 |
| Swipe 滑动 | 位移 ≥24pt | 仅翻页，不触发核心决策 |
| 死区 | 位移 8–24pt | 视为无效，不触发任何操作 |

### 5.3 防误触策略

1. **长按确认**：结束回合/撤退/删除 → 长按出现 300ms 进度圈，完成才触发；途中抬起即取消。
2. **滑动取消**：可选方案——按下高危键后滑出按钮范围即取消（与长按二选一，推荐长按更直观）。
3. **模态拦截**：确认弹窗出现时锁定底层操作，防连点穿透。
4. **边缘安全区**：滑动翻页与系统返回手势冲突时，顶部 30pt、侧边 20pt 设为手势安全区，不放可点目标。
5. **误触拦截统计**：埋点记录「触发后 500ms 内撤销/取消」比例，作为误触率指标。

### 5.4 操作反馈（输入—反馈闭环）

| 事件 | 反馈 |
|---|---|
| 点按命中 | <100ms 视觉高亮（缩放 0.96 + 金框） |
| 选技能/目标 | 即时音效 + 锁定环 + 目标高亮 |
| 蓄力/长按确认 | 持续进度圈 + 轻微震动（haptics） |
| 命中/暴击/治疗 | 短促震动 + 高频音 + 飘字（白/金/绿） |
| 冷却中 | 倒计时数字 + 暗化 + disabled tooltip |

## 6. 左右手适配方案（镜像布局）

**默认右手**，设置页提供「惯用手：右手 / 左手」一键切换（可加「自动」）。

### 6.1 镜像规则

| 维度 | 右手（默认） | 左手（镜像） |
|---|---|---|
| X 轴 | 主操作/CTA 落右下角 | 主操作/CTA 落左下角 |
| 技能卡顺序 | 1–4 从左到右 | 4–1 从左到右（语义镜像，非仅坐标） |
| 结束回合 | 最右侧 | 最左侧（仍独立+长按确认） |
| 左侧纵向导航 | 左侧 | 右侧 |
| 返回/撤退 | 左上 | 右上 |
| 目标锁定环方向 | 无差异 | 无差异 |

### 6.2 差异说明（务必注意）

- **不是简单 flip**：镜像的不仅是坐标，更是「拇指枢轴换边」。左手持机的舒适弧以**左下角**为枢轴，故主操作键必须移到左下，技能卡阅读顺序也要反向，否则玩家按「旧肌肉记忆」会点到错误的卡。
- **只镜像交互层，不镜像内容**：立绘、文字、地图朝向保持不变（战场敌我站位、地图节点布局不翻转）。
- **滚动/手势方向不镜像**：列表滚动、翻页方向对所有玩家一致。
- **布局预设**：支持保存 2 套自定义布局（右手/左手），拖拽微调后一键导出。

## 7. 多尺寸自适应策略

### 7.1 尺寸分档

| 档位 | 宽（pt） | 策略 |
|---|---|---|
| 小手机 | <360 | 技能卡转 2×2 或横滑；单位情报横滑；字号压缩 |
| 标准手机 | 360–430 | 基准单列布局（技能卡 4 列、64pt 主操作） |
| 大手机/小平板 | 430–600 | 单列 + 命中区放大至 64–72pt |
| 平板 | ≥600 | 内容收 560pt 竖栏居中，两侧留深色底；可开「双手双区」 |

### 7.2 安全区

- **刘海/挖孔**：顶部信息条下移 `safe-area-inset-top`，D 区只读信息不顶格。
- **系统手势条/导航条**：底部主操作区上移 `max(env(safe-area-inset-bottom), 24pt)`，避免与 Android 手势条重叠导致「点了返回却触了普攻」。
- **横屏兜底**：手机横屏（高 ≤520pt）显示「请转竖屏」提示层（现有逻辑保留）。

### 7.3 缩放比例

- **按钮不随屏等比缩放**：命中目标保持物理尺寸（≥44pt），用 `clamp()` 锁定最小/最大值，保证可点性。
- **内容区弹性缩放**：以 390pt 为基准，`--scale = min(1, 100vw/390)`，文字/间距用 `clamp()` 收敛；战场、地图用 `dvh/vh` 自适应高度。
- **平板放大**：≥600pt 时命中区放大到 64–72pt，信息字号同步 +1 档，但**操作键保持底部**，不因屏大而散到屏幕中间。

### 7.4 布局重排

| 断点 | 重排动作 |
|---|---|
| 宽 <360 | 技能卡 2×2；单位情报条横滑；建筑卡单列 |
| 360–600 | 基准单列；技能卡 4 列；建筑两列；底部 64px 出发栏 |
| ≥600 | 560pt 竖栏居中；`position:fixed` 的底栏/情报面板/浮层显式对齐 560px（现有 `left:calc(50% - 280px)` 保留） |
| 高 ≤700 | 地图情报面板 34vh（矮屏压缩） |

## 8. 落地清单与验收指标

### 8.1 落地优先级

| 优先级 | 动作 | 预期收益 |
|---|---|---|
| P0 | 战斗：技能卡/普攻/结束回合落底部 A 区，64pt，结束回合独立间距+长按确认 | 每回合操作无上下滚动，误触率下降 |
| P0 | 地图：节点命中区 ≥48，进入节点 CTA 吸底 | 选点→进入零滚动 |
| P0 | 营地：出发 64pt 固定底栏右下角 | 主路径「治疗→编队→出发」单屏完成 |
| P1 | 左右手镜像开关 + 布局预设保存 | 覆盖左手玩家 |
| P1 | 安全区适配（刘海/手势条） | 真机无遮挡误触 |
| P2 | 高危键长按确认 + 埋点 | 可量化验收 |

### 8.2 可量化验收指标

| 指标 | 目标 |
|---|---|
| 单次战斗操作的平均拇指行程 | 单回合 ≤ 1 次上下摆动（无 600px 级滚动） |
| 误触率（触发后 500ms 内撤销/取消） | <5% |
| 高危操作误触发（结束回合/撤退） | <1%（长按确认兜底后） |
| 新手完成首场战斗引导耗时 | ≤3 分钟 |
| 左右手镜像切换后「完成任务时长」差异 | <15% |
| 主观舒适度评分（1–5） | ≥4.0 |

### 8.3 A/B 验证方案

- 对照组：当前「技能卡 + 跳过行动」旧布局；实验组：本方案「技能卡 + 普攻 + 结束回合」落底布局。
- 指标：任务完成时长、误触率、重试率、玩家主观评分，各 ≥20 局真人试玩对比。

*方案依据：《灰烬誓约》V1.1 源码与设计规格（`design-spec.md`）、`DEV_PROGRESS.md` 中 2026-10-29 两轮手机单屏操控优化实测（390×844 战斗页 2150px→单屏、地图节点 39×55→49×68px 等）。本方案为经验性建议，具体手感需以真机试玩数据迭代。*
