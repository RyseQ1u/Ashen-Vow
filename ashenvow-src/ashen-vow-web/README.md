# Ashen Vow V1.0 — 灰烬誓约 Web 单机游戏

本版本为纯浏览器单机游戏，不需要后端。首次开始游戏显示六步指南。玩家可在顶部查阅图鉴，在营地查看成就，存档管理可恢复两份历史快照。

**运行：** 直接打开独立 `ashen-vow-play-v1.0.html`，或运行 `npm run dev` 并访问 `http://127.0.0.1:5173`。必须使用同一浏览器、同一地址访问才能复用本地站点存储。

**测试：** `npm test`；**打包单文件：** `npm run build:standalone`；**经济审计：** `node tools/balance-audit.js`。

详细变化及本机存档验收步骤参见 `RELEASE_NOTES_V10.md`。

# Ashen Vow / 灰烬誓约 — Web V0.9

原创暗黑奇幻单机回合制地牢游戏。**纯 Web、无账号、无业务后端、无需联网**；运行与存档均在浏览器本地完成。

## 下载与运行

- 直接用 Chrome / Edge 打开 `ashen-vow-play-v0.9.html`。单文件版已内嵌样式、三个地牢场景 SVG 和 JS，可以离线运行。
- 源码版需要 Node.js 20+；在 `ashen-vow-web` 目录运行 `npm run dev`，使用输出的本地网址打开。Windows 可双击 `start-game.bat`。
- `npm test` 运行游戏规则和页面模板测试；`npm run build:standalone` 将生成 `../ashen-vow-play-v0.9.html`。

## V0.9 更新内容（战斗表现与事件演出）

- **战斗反馈层**：战斗动作前后对比单位生命、压力与异常状态变化，同时显示伤害、治疗、压力与异常状态字样；支持多目标受到伤害、治疗和 Boss 增援，包含暴击高亮、受击/治疗动画、技能施放标题。
- **实时战斗摘要**：战场下方新增最新行动描述，并与已有滚动战斗日志配合，降低文字信息查阅成本。实际战斗数值仍由 `src/engine.js` 计算，展示层不改写游戏状态。
- **事件场景演出**：根据遭遇标题将界面分为商队、预言、伏击、秘库、篝火、未知事件六类视觉场景，并随墓窟、沼泽、铸炉地区变换氛围色；选择和后果仍遵循原游戏规则。
- **音效和速度**：增加 0–100 音效音量与沉浸/标准/快速三种**演出速度**，保存在 `localStorage`。速度只调整动画显示时间，不改变行动顺序、游戏计算或敌方回合。
- **无障碍和性能**：继续支持减少动态效果，并尊重系统的 `prefers-reduced-motion`；动画节点自动清理，不持久化到存档。
- **兼容性**：引擎存档 `schemaVersion: 1` 未变，V0.1–V0.8 存档数据结构继续兼容；仍为无依赖 JS/CSS 本地 Web 原型。
- **验证**：80 项 Node 自动化测试通过，隔离 Chromium 验证音量、演出速度、地图、技能点击、战斗反馈、事件场景，未发现脚本异常。

**测试边界**：容器禁止浏览器导航本地 URL，Chromium 交互验收采用独立 HTML 注入页面和模拟设置存储，不能在此环境验证真正的 IndexedDB 关闭重开恢复。建议升级前导出 JSON 备份，并始终在同一固定网站地址运行游戏。

## V0.8 更新内容（远征体验、经济韧性与游戏设置）

- **两种新遭遇**：盲眼预言者与断轮商队，分别提供压力/遗物兑换、金币/补给交易及护送选择；资源不足时交易会被拒绝，不会扣成负数。
- **战斗行动预判**：敌方阵容上方显示各单位可能使用的攻击类型和危险等级。预判不锁定目标、不暴露随机数结果，Boss 每第三回合展示群体威胁提示。
- **远征编年史**：营地新增「远征记录」，记录 V0.8 起最近 20 次远征的地区、难度、收益与结局，展示最近 10 条及汇总。旧存档没有对应收益记录，不补造历史数据。
- **长线经济保护**：当连续两次远征全队溃败，且结算后营地金币小于 35 时，发放一次 40 金币和基础火把/绷带；条件不满足不发放，撤退和胜利会重置溃败连击。
- **界面设置**：新增大字体、精简战斗日志开关，沿用原有音效/减少动效。设置写入浏览器 localStorage，存档继续写入 IndexedDB。
- **兼容性**：继续使用 schemaVersion 1，能读取 V0.1–V0.7 存档，新的统计字段按需补充，不更改原有战斗、装备和职业数据。
- **验证**：74 项 Node 规则/模板测试通过；隔离 Chromium 渲染并点击验证设置、营地记录、两种新事件、战斗意图，未出现页面脚本异常。浏览器真实地址的跨会话 IndexedDB 恢复仍需玩家本机确认。

**测试边界**：容器禁止浏览器导航本地文件及 HTTP 地址。浏览器交互采用单文件页面注入，使用模拟的设置存储并绕过被禁止的 IndexedDB 写入，仅用于前端交互验证，不构成真实持久化测试。

## V0.7 更新内容（英雄构筑与战斗策略）

- **18 × 2 条技能专精**：六职业各三种技能，在升级到 +1 后可以选择两条互斥分支之一，例如破甲 / 加伤、附加标记 / 暴击、净化毒血 / 强化治疗等，专精在战斗中真实生效。
  - 首次选择 35 金币 + 3 碎片，更换专精 22 金币 + 2 碎片；只能在营地调整。
- **四套双件饰品套装**：守墓誓约（护甲和开场守护）、暮影之猎（攻击暴击）、灰烬祷仪（治疗、抗压、开场减压）、孤灯旅人（速度和生命）。同一英雄两槽装备恰当的基底时自动激活。
- **特质治疗与远征成长**：城镇伤患管理可以花费金币和碎片移除已拥有的负面特质；远征后按照结果有有限概率获得正/负特质，最多三种，使用可复现的存档随机数。
- **敌人抗性与 AI**：亡灵、沼泽、铸炉敌人对中毒/流血/眩晕有差异化抗性，Boss 眩晕抗性较高；远程敌人更容易攻击残血目标与后排治疗者，近战优先前排。
- **逐区长期挑战曲线**：地区每累积 3 次通关，威胁等级 +1，最多 4 级；后续敌人生命、攻击和结算收益渐进上升。独立于巡礼/苦修/无光难度。
- **持久化**：仍使用 `schemaVersion: 1`，旧 V0.1–V0.6 存档会自动补齐新字段。三个 IndexedDB 存档槽以及 JSON 导入/导出保持不变。
- **质量验证**：64 个 Node 自动化用例通过，且在隔离 Chromium 中点击验证技能专精、负面特质治疗、装备套装和战斗 UI，未发现 JS 异常。

**范围说明**：当前是零第三方依赖的 JavaScript/CSS 单机原型，不是 React/Phaser 项目；没有业务后端、Android 包装或云存储。测试容器禁止浏览器导航本地 URL，因此无法验证真实网址下跨会话的 IndexedDB 持久化，需要在本机单独确认。请在升级前导出 JSON 备份。

## V0.6 更新内容（长期可玩性）

- **3 档地牢挑战难度**：巡礼（正常）、苦修（敌人生命 +20% / 攻击 +15%）、无光（生命 +45% / 攻击 +30%，开局额外压力）。对应提高撤离和通关时带回的金币、碎片；难度仅在营地选择。
- **职业技能强化**：6 职业、18 项技能均可在营地「技能训练」界面升级至 +2。伤害技能每级 +0.12 威力系数；治疗、减压技能增加固定效果；守护、标记增加持续时间。训练消耗金币、遗物碎片，升级状态持久化。
- **英雄正负特质**：英雄拥有 1 个正面和 1 个负面特质，影响攻击、生命、速度、命中、抗压。新招募英雄同样拥有特质；旧存档会按英雄 ID 自动、稳定地补充（无随机覆盖）。
- **压力崩溃分型**：达到 100 压力后出现恐惧、狂怒或绝望；恐惧可能损失行动、狂怒增强攻击但减命中、绝望减命中且更易增加压力。压力回落至 65 以下解除。
- **特殊房间**：破晓祭坛、伏击回廊、遗物秘库。可净化压力、突围触发精英战、破解封印取得稀有饰品或安全搜集补给。
- **扩充饰品**：饰品基底从 8 扩至 12，词缀从 8 扩至 12；新增具有加减属性取舍的诅咒、鲁莽等词缀，延续原有两槽装备系统。
- **存档兼容性**：保留 `schemaVersion: 1`，V0.1–V0.5 存档继续可读取，新字段以默认值补齐。**升级前先导出 JSON 备份。**

**范围说明：** V0.6 实现技能数值升级，未制作分叉技能树（作为后续任务）。游戏仍为纯 JavaScript + CSS 的单机原型，不使用 React/Phaser，也没有 Android 或服务器。由于环境禁止通过真实文件网址自动导航，完整的持久化关闭重开验证仍需玩家在本机完成。

## V0.5 更新内容

### 地牢地区选择

在营地右侧选择地牢；**选择仅能在营地更改**。本次同时开放三个地区，暂无解锁门槛：

| 地区 | 地方特色 | 地图危险 | 首领 | 远征金币倍率 / 遗物碎片倍率 |
|---|---|---|---|---|
| 暮影墓窟 | 亡灵、咒术和压力 | 每 3 回合额外增加一名英雄压力 | 噬誓者 | ×1.0 / ×1.0 |
| 腐潮沼泽 | 中毒和瘴气 | 每 3 回合随机一名英雄中毒 | 瘟沼之母 | ×1.2 / ×1.25 |
| 熔烬铸炉 | 高护甲和重击 | 每 3 回合全队受到 3 点灼烧伤害（不会由此减至 0 HP） | 永燃炉心 | ×1.4 / ×1.5 |

收益倍率作用于撤退或胜利后带回的金币与碎片，和原有出征策略倍率共同计算；失败只保留部分基础金币，不吃倍率。

### 战斗与事件

- 各地区独立普通怪物池、精英组合、最终 Boss 组合。
- 新增 **12 类敌人**：沼泽 6 类（包括 Boss）、铸炉 6 类（包括 Boss）；原 11 类仍然可用。
- 精英战出现地区对应词缀：墓窟「铁甲精英」额外护甲；沼泽「腐毒精英」攻击可使英雄中毒；铸炉「狂热精英」攻击及速度提高。
- 三名 Boss 生命下降到 **65% / 30%** 附近时进入第二、第三阶段，提升攻击和护甲；第二阶段增援，第三阶段全队压力增加。阶段随存档保留。
- 三个地区不同的原创探索事件及选择结果。沼泽无火把时提供不耗火把的替代选项，避免卡住。
- 三个原创场景：墓窟（旧版）、沼泽（新增 SVG）、铸炉（新增 SVG）；战斗背景、地图和事件主题相应切换。
- 每个地区单独累计通关次数，显示于营地地区选择卡片。

## 存档说明

- **三槽本地存档、自动保存、JSON 导入/导出**保持不变；存储使用 IndexedDB。
- 原 V0.1–V0.4 存档可以读取。旧存档新增默认选区 `crypt`，各地区通关计数为 0；旧版进行中的远征/战斗统一视为墓窟，不会中途变区。
- **升级前推荐在旧版本存档管理中导出 JSON**。单 HTML 的 `file://` 存储隔离可能随浏览器而异；和 `http://127.0.0.1:5173` 并不共享浏览器来源。需要跨版本切换地址时，使用导入/导出迁移。
- 浏览器清理网站数据、无痕模式、浏览器存储策略可能造成存档丢失。无云端备份。

## 技术实现

当前仍是 **零第三方前端依赖的原生 JavaScript 原型**，不是计划中的 React + Phaser 版本。其设计为：

```text
ashen-vow-web/
  src/engine.js             # 独立游戏规则、战斗、地区、存档校验
  src/ui.js                 # 单页界面与交互
  src/storage.js            # IndexedDB 与 JSON 备份
  assets/*.svg              # 3 张原创地区背景
  style.css                 # 响应式 CSS 及地区主题
  tests/*.test.js           # node --test 自动化测试
  tools/build-standalone.js # 单 HTML 内嵌打包
  tools/serve.js            # 本地静态开发服务
```

## 已执行的测试

- `npm test`：**64/64** 通过（包括 V0.7 技能分支、套装、抗性、负面特质治疗、威胁增长与旧存档字段迁移）。
- 隔离 Chromium 页面：实际点击三种地区，执行开始远征→事件→精英战（规则模拟进入）→撤退→回营，未出现 JS 运行时异常。已人工查看地区选择和战斗截图。

## 建议验收

1. 先在旧版导出 JSON 存档，打开 V0.7 导入。
2. 选择「腐潮沼泽」，进入地牢，确认绿色战斗背景、瘴气事件和腐毒精英。
3. 撤退回营，切换到「熔烬铸炉」，确认背景切换、火焰环境伤害。
4. 走到终层挑战地区首领，确认战斗阶段转变、战利品结算、地区通关次数。
5. 关闭浏览器重新打开**同一个地址**，继续存档；再导出备份并尝试导入另一槽位。

本作品使用原创标题、美术表现与游戏内容；借鉴黑暗风格策略回合制玩法，但不使用其他游戏的素材、人物或商标。
