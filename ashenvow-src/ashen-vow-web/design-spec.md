## 2. 主菜单（目标）

- 全屏厚涂主视觉（红月城堡+四英雄剪影），底部渐隐。
- Logo 居中：中文「灰烬誓约」+ 英文 `ASHEN OATH`（统一定稿，不再混用 VOW/OATH）+ 纹章符号。
- 右上玩家卡：头像 + 旅者名 + `Lv.N` + 细经验条。
- 中部 4 张主按钮大卡（各带缩略插画）：**开始远征 / 继续游戏 / 图鉴 / 设置**。
- 左下存档卡：`存档·名称` + `Lv.N` + `YYYY/MM/DD HH:mm` + 切换图标。
- 右下版本号 `V1.0`。

## 3. 营地（目标）

- 顶部资源栏：金币 ⛁ `723` · 碎片 ❖ `3` · 第三资源 ◆ `1` · 右侧邮件/设置/暂停图标。
- 左侧纵向导航（3 项）：**营地 / 英雄 / 档案**（图标+竖排文字）。
- 中央场景：4 张建筑浮卡（医馆/礼拜堂/工坊/守夜塔），每张=图标+名称+`Lv.n`+一句话描述。
- 场景下快捷四动作（大按钮）：**治疗 / 训练 / 锻造 / 升级**。
- 底部远征队伍条：4 张横卡 = 立绘+名字+职业+`Lv.n`+HP 红条+经验蓝条+3 状态图标位。
- 后备英雄：`n/8` 横排小头像 + 加号空槽。
- 右下巨型 CTA：**出发**。
- 右上浮动提示卡：「新的远征」等轻通知。

## 4. 远征地图（目标）

- 顶部地区页签 ×3：插画缩略 + 地区名 + 副题（暮影墓窟/腐潮沼泽/熔烬铸炉）。
- 地图：手绘羊皮纸风底图 + 节点（图标+名称），已完成节点绿勾，当前节点高亮金框。
- 右侧节点详情面板：节点名 + 类型徽章（普通节点/精英/事件…）、描述、**可能遭遇**（敌人头像排）、**通关奖励（概率）**、**风险评估**（骷髅 ×1–5）、**推荐战力**（数值）。
- 底部：队伍横条（头像+HP）+ 补给栏 4 类带容量：火把 `15/20`、绷带 `8/10`、治疗药剂 `3/5`、圣徽 `2/3`。
- 右下按钮：**背包**（左）+ **撤退** + **进入节点**（金色 CTA，两段式：先选中预览，再进入）。

## 5. 战斗（目标）

- 标题行：`地区·第N层` + 副题（战型）。
- 顶部行动顺序：**头像胶囊条**，当前行动者金框高亮；敌我用描边色区分。
- 战场：双方对峙立绘，脚下 HP 红条 + 状态图标行；当前单位金色光环，可选目标红色锁定环；伤害飘字（白/暴击金/治疗绿）。
- 右侧战斗日志：竖排，伤害红、治疗绿、系统灰。
- 左下当前英雄面板：立绘 + 名字 + 职业/称号 + `Lv.n` + HP `204/204` + **经验 `10/100`** + 四维（攻击/防御/暴击/速度）+ 「详情」。
- 技能区：**4 张技能卡**（含普攻卡位）：卡名 + 插画 + **类型标签**（伤害/防御/增益/终结）+ 技能点/冷却圆点；不可用灰态。
- 右侧主操作：**攻击**（普攻，100% 攻击力）+ **结束回合**。
- 快捷键：`1–4` 技能、`A` 普攻、`Space` 结束回合、`Esc` 取消选择。

## 7. 交互规则

1. 地图两段式：点节点=选中预览（面板滑入），点「进入节点」才推进。
2. 战斗选技能→可选目标高亮→点目标结算；再点技能卡取消。
3. 「攻击」= 普攻快捷路径（选目标后立即结算）。
4. 所有不可用操作按钮 disabled + tooltip 说明原因（金币不足/冷却中/不在阶段）。
5. 尊重 `prefers-reduced-motion` 与「减少动效」开关；动画时长随「演出速度」缩放。
